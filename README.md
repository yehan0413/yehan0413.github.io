# Han Ye - Academic Website

A simple, responsive academic website prepared for GitHub Pages. It has no build step or software dependencies.

## Preview locally

Open `index.html` directly in a browser, or run a small local web server from this folder.

## Publish with GitHub Pages

1. Create a public GitHub repository. For the shortest address, name it `<your-github-username>.github.io`.
2. Upload all files in this folder to the repository's main branch.
3. In the repository, open **Settings > Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, then choose `main` and `/ (root)`.

The site will appear at `https://<your-github-username>.github.io/`.

## Update the site

- Edit biography and research entries in `index.html`.
- Replace `assets/profile.jpg` to change the portrait while keeping the same filename.
- Adjust colors and typography near the top of `styles.css`.

The current design uses Google Fonts. The site remains readable if those fonts are unavailable.
